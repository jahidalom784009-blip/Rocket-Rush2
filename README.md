# Rocket Rush — Stone Breaker

Mobile-first portrait rocket shooter inspired by the supplied screenshot.

- Rocket points upward and stays in flight.
- Hold FIRE for unlimited ammo.
- Destroy falling stones to score points.
- Touch the playfield to steer the rocket horizontally.
- Pause, restart, saved best score, offline PWA support.

## Publish with GitHub Pages
1. Create a public repository (e.g. `rocket-rush`).
2. Upload all files from this folder into the repository root, not the ZIP file.
3. Open Settings → Pages.
4. Choose Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Open the Pages URL after deployment finishes.
6. On Android Chrome, use ⋮ → Install app / Add to Home screen.
